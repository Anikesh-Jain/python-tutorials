# Python Tutorials 🐍

A collection of Python fundamentals, practice programs, and beginner-friendly projects created during my Python learning journey.

## Topics Covered

- **Basics:** Variables, input, reserved keywords, type conversion, and type casting
- **Complex Data Types:** Lists, tuples, sets, dictionaries, and their methods
- **Conditional Statements:** If-else and elif
- **Loops:** For loops, while loops, range, break, and continue
- **Functions:** Built-in functions, user-defined functions, and modules
- **Operators:** Arithmetic, assignment, comparison, logical operators, and precedence
- **String Methods:** Case conversion, searching, checking presence, and replacing text

## Projects

### Calculator
A command-line calculator supporting addition, subtraction, multiplication, division, modulus, and exponentiation.

### Guess the Number
A number-guessing game using a randomly generated number between 1 and 50.

## Requirements

- Python 3
- Any code editor or terminal

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Anikesh-Jain/python-tutorials.git
cd python-tutorials
```

Run an example:

```bash
python "Basics/helloWorld.py"
```

Run the projects:

```bash
python project/calculator.py
python project/guessGame.py
```

Use `python3` instead of `python` if required by your system.
